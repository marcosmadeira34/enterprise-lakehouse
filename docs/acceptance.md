## Known limitations

* **CI not executed**: `.github/workflows/ci.yml` mirrors the local commands but the repository has no
  remote yet, so the workflow has never run on GitHub.
* **MinIO image is frozen** (`bitnamilegacy/minio:2025.7.23`); upstream images are no longer published
  (ADR-0006). Pipelines use the MinIO root credentials (local only).
* **Spark local mode** in the Airflow worker; no cluster. Fixed per-job overhead dominates below ~1 M
  records (`docs/benchmark.md`).
* **Gold is fully rebuilt** on every publication; product cost is SCD type 1.
* **No source deletes** (tombstones) and no Alembic migrations yet.
* **No Alertmanager receiver**: alert rules evaluate in Prometheus only.
* **Security** is lab-grade: no TLS/auth on the API, Airflow all-admins (see `docs/security.md`).
* The Airflow image is large (Airflow base + Java + PySpark + ~550 MB Ivy cache with the AWS SDK bundle).
